# 📷 Vos images

Déposez ici vos photos. Elles seront accessibles sur le site via un chemin
commençant par `/images/...`.

## Photos de chantier (projets)

Placez vos photos dans le sous-dossier `projets/`.

Les noms de fichiers doivent correspondre à ceux indiqués dans les fiches projets
(dossier `src/content/projets/`). Par exemple, pour la fiche du duplex :

```
projets/duplex-1.jpg
projets/duplex-2.jpg
projets/duplex-3.jpg
```

Conseils :
- Format **JPG** ou **WebP**, largeur recommandée **1600 px**, poids < 400 Ko.
- Tant qu'une photo n'est pas présente, un cadre « Photo à insérer » s'affiche.

## Image de partage social (Open Graph)

Remplacez le fichier `og-expertreno.jpg` (à créer ici) par une image de
**1200 × 630 px**. C'est l'aperçu affiché quand on partage le site sur
WhatsApp, LinkedIn, Facebook, etc. (voir `src/components/Seo.astro`).
